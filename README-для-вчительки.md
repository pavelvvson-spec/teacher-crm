# Інструкція користування системою

## Вхід у систему
Відкрий сайт, введи email і пароль.

## Головна сторінка
Тут швидкі кнопки для додавання учня та створення уроку.

## Учні
- **Додати учня**: кнопка "+ Додати учня", заповни ім'я (обов'язково), решту полів — за бажанням.
- **Редагувати учня**: клікни на учня в списку, зміни потрібні поля, натисни "Зберегти".
- **Сталий графік**: у картці учня внизу можна додати регулярні дні занять (наприклад "Понеділок 17:00") — уроки на 8 тижнів наперед створяться автоматично.
- **Деактивувати учня**: кнопка "Деактивувати" в картці учня (учень залишається в базі, але зникає зі списку активних).

## Календар
- Перемикай між виглядом День / Тиждень / Місяць.
- Кнопка "+ Створити урок" — для одноразового уроку або нового сталого графіку.
- Клікни на будь-який урок, щоб:
  - позначити "Проведено" або "Учень не прийшов"
  - позначити оплаченим
  - надіслати нагадування в Telegram вручну
  - перенести урок на інший час
  - скасувати урок

## Оплати
Показує загальний борг учнів і дохід за поточний місяць.

## Звіти
Обери період (від — до), побач кількість уроків, суми, список боржників за цей період.

## Telegram
- Тут видно, хто з учнів підключив Telegram (натиснув Start у боті).
- Щоб підключити учня: вкажи його Telegram username у картці учня, попроси його знайти бота і натиснути Start.
- Тут же журнал усіх надісланих нагадувань.

## Резервне копіювання бази даних
Файл бази даних називається `dev.db` (у корені проєкту). Раз на тиждень рекомендується копіювати цей файл кудись у безпечне місце (флешка, Google Drive) — на випадок проблем з комп'ютером.
